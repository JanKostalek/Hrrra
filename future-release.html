Hrrra Future Release Changes

Updated: March 29, 2026

This page lists changes that are already planned or currently in progress for a future Hrrra build. If you are testing the current version, please check here before reporting a suggestion that may already be in the pipeline.

Currently Planned

  • Frame rate tuning for the individual character animation sets.
  • Improvements to the individual character animations.
  • Visual updates for the individual levels, including new art for platforms, elevators, and later additional in-game assets.

How To Use This Page

  • If something you wanted to report is already listed here, it means the change is planned and does not need to be reported again unless you have extra detail.
  • If your issue is not listed here, please report it normally.
  • This page may change between app releases, even before a new build is published to the store.

Tester Note

This page is intentionally lightweight and can be updated separately from the Android build, so testers can always see the latest planned changes online.
