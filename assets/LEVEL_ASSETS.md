Level-specific art folders live here:

- `assets/level1/`
- `assets/level2/`
- `assets/level3/`
- `assets/level4/`
- `assets/level5/`

If a file exists in a level folder, the game uses it only for that level.
If it does not exist, the game falls back to the current shared asset.

Supported level-specific filenames:

- `background_sky_tile.png`
- `background_foreground_tile.png`
- `background_back_tile.png`
- `background_mid_tile.png`
- `background_front_tile.png`
- `platform.png`
- `elevator.png`
- `blocker.png`
- `coin.png`
- `moneybag.png`
- `heart.png`
- `rocket01.png`
- `rocket02.png`
